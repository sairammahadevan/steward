The Problem

You have a flat. A car. A water purifier. An insurance policy. An AMC for your AC. A warranty for the fridge. Receipts. Property papers. Legal deeds.

They're scattered across email, WhatsApp, a physical drawer, and a Downloads folder. You only remember they exist when something breaks — or expires.

STEWARD fixes this.

What It Does
📄→🧠
Reads any document

Upload a PDF, DOCX, or paste text. STEWARD parses it — including scanned/image-based PDFs using Claude's vision model. It extracts the item name, document type, purchase date, next due date, tags, and notes automatically.

📧
Email to ingest

Configure your Gmail address once. Then forward any document directly — no app needed. STEWARD polls your inbox every few minutes, downloads attachments, and processes them in the background.

💬
Ask anything

Multi-turn conversation with your vault. Ask "What's my property survey number?" or "Which warranties expire this year?" — STEWARD reads the actual documents and answers in plain English, citing which file it used.

📂
Organised automatically

Documents are grouped by type — AMC, Warranty, Legal, Insurance, Receipt. Instant search across names, types, tags, and dates. Filter by type with one click. Mark documents done when resolved.

⚠️→✓
Overdue tracking

STEWARD flags documents past their due date in red — bike service overdue, AMC renewal missed, insurance expiry approaching. Mark them done once resolved. The due date strikes through.

↺
Re-ingest at higher quality

Got a bad extraction on a scanned document? Hit Re-ingest from the Documents page or mid-conversation in Ask. It re-runs at 150 DPI with Claude Sonnet vision — far better results for low-quality scans.

How It Works
1
Drop a document

Upload via the web UI, drag and drop multiple files, or email an attachment to your configured Gmail address.

↓
2
STEWARD parses and extracts

PyMuPDF reads text PDFs directly. Scanned pages are rendered as images and sent to Claude Sonnet for OCR-quality extraction. DOCX and plain text are handled natively.

↓
3
Metadata card saved locally

A structured record lands in your local SQLite database — item, type, dates, tags, notes — all searchable instantly. The original file stays on your disk, untouched.

↓
4
Ask, browse, act

Chat with your vault in plain English. Search and filter by type. Open the original file in one click. Mark things done. Re-ingest if an extraction was off.

Privacy
🖥
Files never leave your machine

STEWARD stores documents in a local folder. The database is a single file on your disk. Nothing is uploaded to any cloud storage.

🔒
API calls are transient

Only document text (not the file itself) is sent to the Anthropic API during processing. Anthropic deletes this within 7 days and never uses it for model training.

✋
You control the key

Your Anthropic API key lives in a .env file on your machine. STEWARD never transmits it or logs it anywhere.
